# 馬券種別・固定100円評価

単勝、複勝、馬連、馬単、3連複、3連単を別々に集計する。異なる馬券種の的中率や回収率を合算せず、各買い目は1点100円に固定する。

## 出力指標

馬券種ごとに次を出力する。

- 買い目数と的中数
- 的中率
- 購入額と払戻額
- 回収率
- 最高払戻を除外した回収率
- 最高払戻が全払戻に占める割合
- 上位3件・5件の払戻集中度

最高払戻を除外する場合も、その買い目へ支払った100円は購入額から除外しない。これは、少数の高配当だけで回収率が支えられていないかを見る感度分析である。

## 買い目の同一性

馬連と3連複は順序を持たないため、馬の並びだけを変えた買い目は重複として拒否する。馬単と3連単は着順が異なれば別の買い目として扱う。同一レース・同一馬券種・同一買い目の重複記録は集計しない。

この評価層は購入戦略を変更しない。実購入候補は引き続き、事前固定した三連単1点100円だけであり、他の馬券種は独立した研究評価として扱う。
