# 確率予測モデル

段階5の最初のモデルとして、外部ライブラリに依存しないレース内条件付きロジットを実装する。これは最終モデルではなく、特徴量が比較用ベースラインを上回るか検証するための、説明可能で再現可能な出発点である。

## 学習

- 1レースを1つの選択集合とし、1着馬の条件付き対数尤度を最小化する
- 入力特徴量を学習データ内で標準化する
- L2正則化付きのバッチ勾配降下を固定順・固定反復回数で実行する
- 同着1着は信用を同着馬へ等分する
- 学習最終時刻を保存し、それ以前または同時刻のレースは予測しない

乱数を使用しないため、入力、反復回数、学習率、正則化強度が同じなら係数と予測も同じになる。

## ローカル学習成果物

権利確認済みのローカル学習CSVから、時点安全な特徴量生成と条件付きロジット学習を一括実行できる。

```bash
PYTHONPATH=src python -m keiba_prediction_lab.cli train-model \
  local/training.csv --output local/model.json
```

確率の過信を抑える正式運用では、時系列で新しいレースを校正専用に確保できる。
次の例は末尾60レースを係数学習から除外し、温度スケーリングだけに使う。
校正期間は学習期間より後でなければならず、予測順位は変えずに勝率と三連単確率の
強弱だけを補正する。

```bash
PYTHONPATH=src python -m keiba_prediction_lab.cli train-model \
  local/training.csv --calibration-races 60 \
  --output local/calibrated-model.json
```

成果物には、学習CSVのSHA-256と対応する入力データ版、学習行・レース数、事前分布強度、反復回数、学習率、L2強度、校正レース数、特徴量名と順序、係数、標準化値、学習終了時刻、任意の校正終了時刻と温度、モデル版を保存する。同じ入力と設定からは同じ内容ハッシュを生成する。保存済みファイルは上書きせず、読込時に内容ハッシュ、特徴量契約、数値の有限性、来歴の整合を検証する。旧スキーマ1.0の未校正モデルも引き続き読み込める。

## 出力確率

- 勝率はレース内softmaxで計算し、合計を必ず1とする
- 3着内率は同じ潜在強度を使ったPlackett–Luce分布から厳密に計算する
- 3着内率の合計は出走頭数と3の小さい方になる
- 予測順位は勝率の降順とし、同率時は馬番順で固定する

評価には比較用ベースラインと同じBrier score、Log loss、1着的中率を使用する。モデル選択期間と最終評価期間の分離は、段階7のウォークフォワード検証で実装する。

## 確率校正と時間分離

初期モデルとは別の、学習終了後の期間を使って温度スケーリングを行う。候補温度のうち、校正期間の1着対数損失が最小になる値を決定的に選ぶ。温度は勝率の確信度だけを調整し、予測順位は変更しない。3着内率も調整後の同じ潜在強度から再計算する。

期間は必ず `学習 < 校正 < 最終評価` の順にする。コードは、学習期間以前の校正と、校正期間以前または同時刻の最終予測を拒否する。確率校正の診断には、確率帯ごとの件数、平均予測率、実測率とECEを出力する。

## 現時点の制約

- 合成データだけで動作契約を確認しており、実競馬に対する精度改善はまだ主張しない
- 条件付きロジットは馬同士の相対強度を線形に表現する
- LightGBM等の非線形モデルは、利用可能な実データ源を承認した後に同一評価契約で比較する
