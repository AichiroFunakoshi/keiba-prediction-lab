# オッズを入力しない独自予測

`--ability-v5` は近走v4の入力に、過去対戦の相対評価、頭数を考慮した近走成績、同競馬場・路面および同距離帯・路面での成績、騎手の競馬場・路面別勝率、前走からの斤量差を追加する。オッズ・人気・払戻を特徴量にも学習目標にも使わない。

相対評価は結果既知時刻順に過去レースを再生する。各馬の初期値は0。レース前の評価差をロジスティック変換して対戦勝率を求め、実際の相互着順（同着は0.5）との差の対戦相手平均を0.25倍して更新する。レース内の更新は全馬の更新前評価を使う。近走成績は「倒した相手数＋同着相手数×0.5」を相手数で割り、既存の直近5走・90日半減期で集約する。コース・距離成績は同じ指標を中立値0.5へ縮約する。

これは取得済みの対戦履歴による相対評価であり、公式レーティング、クラス調整済み時計、完全な生涯成績ではない。未取得の時計・着差・相手クラスを補完したことにはしない。既存の脚質・ペース処理は引き続き別の影予測であり、このモデルの入力に混ぜたとは主張しない。

モデル保存形式は1.5。旧1.0〜1.4の読込と旧モデルの入力ベクトルを維持する。モデルの時点と入力の結果既知時刻の検査を引き継ぐ。モデル選定は事前に固定した同一期間で行い、次の未使用開催で事前予測を保存する。再学習したモデルの本番成績は、その後のレースで測定する。

## 運用

ローカル予測設定の `market_weight` に0を指定すると、主表示は独自予測100%となる。市場スナップショットは主表示の順位・確率計算に不要で、`market-blend.json` を作らない。独自WIN5も各独自予測から作る。市場を使う比較設定を併設できるが、その出力は別ディレクトリに保存する。

既存の `predict-profile-day` に履歴、計画、市場スナップショットのパスを渡す。独自設定だけなら市場パスは存在しなくてもよい。比較設定が市場を使用する場合は、既存の取得時刻・ハッシュ検査を必須とする。

予測根拠は実際の線形スコアの寄与を表示する。特徴量ごとに「当該馬の値 − 同レース平均」を学習時の標準偏差で割り、係数を掛け、校正温度で割る。寄与合計は対数勝率のレース平均からの差に一致する。これはモデル内の説明であり、因果的な勝因でも勝率の増減ポイントでもない。

根拠ファイルは予測と同じ入力から作り、各馬の確率が保存済み予測と一致しなければ保存しない。モデル・開催日への対応とファイル整合性を検査して表示する。欠測を表示し、未知の成績を既知のゼロ成績と説明しない。
