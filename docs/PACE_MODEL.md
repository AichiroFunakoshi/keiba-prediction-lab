# 展開条件付き三連単モデル

段階6の第2基準線として、1着馬が異なると2・3着の成立局面も変わる、という仮説を明示的に表現する。

## 入力

各馬について、予測時点までに確定した次の値を受け取る。

- 脚質：逃げ相当、先行相当、中団相当、差し・追込相当
- 序盤速度 `early_speed`
- 終盤速度 `late_speed`
- ペース耐性 `pace_resilience`
- 観測時刻

レース全体について、想定ペース（slow / average / fast）とその確信度を受け取る。全値は現段階では外部から明示的に渡す契約であり、実データからの推定器はまだ実装していない。

## 条件付き計算

1着確率は既存の勝率モデルから変更しない。1着馬の脚質と事前の想定ペースから、その馬が勝った局面の実現ペースを作る。残り馬の2着強度は序盤・終盤速度とペース耐性で再重み付けし、3着では終盤速度と耐性をやや強く扱う。

各段階で残存馬の強度を正規化するため、次を満たす。

- 全三連単確率の合計は1
- 各馬が1着となる周辺確率は元の勝率と一致
- 同じ2着候補でも、逃げ馬が勝つ局面と差し馬が勝つ局面で相対確率が変わる

## 現段階の位置付け

`pace-scenario-v1`の係数は学習値ではなく、検証可能な仮説値である。このモデルが勝率だけの`plackett-luce-v1`より優れているとはまだ主張しない。同じ事前固定・時系列評価契約で比較し、未使用期間でも改善が再現した場合だけ次版へ採用する。

`historical-corners-v1`は、確定済み過去走のコーナー順位・終盤の位置上昇・上がり順位・着順から上記入力を自動生成する前処理版である。直近5走に限定し、利用可能走数に応じて0.5へ縮約する。履歴ゼロでは想定ペースを平均、信頼度を0とする。生成値は仮説入力であり、展開モデル自体が検証済みであることを意味しない。

脚質・ペース情報の観測時刻が勝率予測時刻より後の場合、処理は失敗する。展開モデルの出力も通常の影ポートフォリオと同じ形式で発走前に固定保存できる。
