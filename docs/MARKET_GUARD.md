# 市場乖離ガード

## 目的

独立予想の確率・順位を変更せず、単勝オッズ確認後にモデル本命と市場評価が大きく乖離したレースを見送るための研究用ガードである。

`market-disagreement-shadow-v1`は正式予想を上書きしない。出力は`research-shadow`であり、現段階では購入指示ではない。

## 規則

- オッズは条件付きロジットモデルの特徴量へ入れない
- 事前固定済みモデル1位馬の単勝人気だけを確認する
- 既定では3番人気以内を評価対象、4番人気以下を見送り候補とする
- オッズ欠損時は推測せず見送る
- 同一オッズは同順位として扱う
- 閾値、観測時刻、カードと開催日マニフェストのSHA-256を保存する

既定の3位という閾値は、2026年8月30日の36レースでモデル本命4番人気以下が0勝14敗だった事実から作った初期仮説である。同じ日の結果を使った事後仮説なので、改善効果の証拠には数えない。今後300レース以上で事前固定して、的中率、対象レース数、回収率を無ガードと対応比較する。

## 実行

独立予想を先に固定した後、同じ発走前カードスナップショットを別入力として渡す。

```bash
keiba-lab build-market-guard \
  local/jra-web/20260830-predictions \
  local/jra-web/20260830-morning-raw \
  --max-market-rank 3 \
  --output local/jra-web/20260830-market-guard.json
```

全レースについて`eligible`、理由、モデル勝率、単勝オッズ、人気順位を保存する。観測時刻は取得マニフェストから読み、`cards.json`のSHA-256を再検証する。予測時刻より前、または対象レース発走後の観測時刻は拒否する。
