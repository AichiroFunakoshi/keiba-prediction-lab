# 事前予想の固定保存とレポート

段階8では、結果を見る前の予想を変更不能な記録として保存する。保存物には予測時刻、発走予定時刻、入力データ版、モデル版、各馬の確率・順位、1着固定の三連単買い目を含める。

## 保存契約

- `frozen_at`は必ず`scheduled_at`より前
- `pre_odds`と`post_odds`を別スナップショットとして区別
- 各三連単は1点100円固定
- 三連単の1着軸は予測順位1位の馬で統一
- 保存先が存在する場合は上書きせず失敗
- JSONの正規化内容からSHA-256を計算し、読込時に改変を検知
- 元データそのものではなく、利用者が管理する入力データ版識別子を保存

実運用では、予測ファイルを`data/`以下のGit管理対象外領域に保存する。外部データや実予想を公開リポジトリへ自動送信しない。

## 結果とレポート

結果は予想スナップショットとは別のレコードとして渡す。同着により複数の三連単が的中する場合は、組み合わせごとの払戻を保存できる。

Markdownレポートは保存済み予想と結果だけから再生成し、次を分けて表示する。

- オッズ確認前後のレース数
- 1着的中率
- 三連単のレース的中率
- 買い目数と100円固定の購入額
- 払戻額と回収率
- 最高払戻への集中度

回収率は予測精度と分離した診断指標であり、賭け金増額やマーチンゲールによる最適化は行わない。
