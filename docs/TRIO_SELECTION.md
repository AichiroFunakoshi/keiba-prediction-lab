# 三連複を主候補にする運用（trio-joint-probability-v1）

ユーザーによる券種変更の指定を受け、三連複1点100円を主候補とする。投票機能はない。旧三連単成果物の購入記録と監査契約は変更しない。

ローカル予測設定に `"selection_objective": "trio"` を指定し、`predict-profile-day` を実行する。独自版・市場混合比較版とも指定できる。省略時は旧成果物生成との互換性を保つ。三連複指定時は `trio-selection.json` を別途新規保存し、発走前固定時刻、元の確率・モデル・入力のハッシュ、候補と確率を保存する。既存ファイルへの上書きは拒否する。表示時には監査済み元予測から再計算し、保存内容との一致を検証する。

全3頭組について、その3頭が1〜3着を占める6通りの着順確率を合計し、最大の組合せを選ぶ。3頭の個別3着内率の積ではない。各組の確率の合計は1で、同確率の候補は馬ID順で決定する。表示は馬番順で「－」区切りとし、着順の意味を持たせない。

RaceWeaveの主表示は三連複候補と推定的中率を使う。馬番ごとの単勝オッズ・人気・取得時刻も維持する。古い成果物に三連複固定ファイルがない場合は「保存予測から算出した参考候補」と明示し、過去の正式購入記録へ変換しない。WIN5は従来どおり別の1着予測である。

## 精度評価の境界

この版は券種選択の目的を変更するもので、馬の能力モデル・騎手特徴・オッズ混合率の係数を再学習しない。現在のPlackett–Luceモデルでは最大三連複が勝率上位3頭と一致するため、選択馬の変更や精度向上を主張しない。

今後のモデル比較では同じ固定ウォークフォワード期間で、上位3頭順不同的中率と組合せ確率のLog loss・Brier scoreを測定する。1点100円の払戻・回収率と最高払戻除外後の回収率も別々に報告する。直近開催は診断材料とし、係数の選択に利用した日を未使用評価日に数えない。将来の未使用開催で確認するまでは、券種変更による的中率上昇を能力モデル改善と混同しない。
