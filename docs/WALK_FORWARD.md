# ウォークフォワード検証

実運用に近い順序で精度を測るため、拡大型のウォークフォワード検証を使用する。各窓は次の3期間を持つ。

1. `train_end`以前：モデル学習
2. `train_end`より後、`calibration_end`以前：確率校正
3. `calibration_end`より後、`evaluation_end`以前：未来評価

次の窓では前の評価期間までを学習へ追加できる。ただし、評価期間同士は重複させない。すべての境界はタイムゾーン付き時刻で指定し、逆転、重複、空の期間は処理前に拒否する。

## 出力

- 窓ごとの学習・校正・評価レース数と選択温度
- 条件付きロジットモデルの1着的中率、Brier score、Log loss
- 同じ評価レースに対する一様確率ベースラインの同一指標
- 全評価窓を結合した両モデルの指標
- 全評価予測の確率帯別校正表とECE

現段階は合成データによる動作契約の検証であり、実競馬での性能を示すものではない。競馬場、距離、クラス、頭数、信頼度別の診断と300〜500レース規模の追跡は、利用可能な実データ源の承認後に追加する。
