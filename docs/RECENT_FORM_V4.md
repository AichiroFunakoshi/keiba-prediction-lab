# 近走・乗り替わり・前走条件を扱う独立モデル候補

`--recent-form-v4` は `evidence-neutral-v3` をベースに、オッズを使わず以下を加える任意選択のモデルである。既定モデル・過去の予測は変更しない。

- 保存済み直近5走の着順逆数（1/着順）の加重平均
- 同じ直近5走の3着内率（同着は既存の入着信用を使用）
- 近走履歴なしのフラグ
- 当該馬と今回の騎手の組み合わせの3着内率（既存の事前強度で平滑化）
- 直前の保存走からの距離増減（km）と芝・ダート・障害の変更
- 直前の保存走からの馬体重変化率、および変化率不明のフラグ

近走の重みは観測時刻までの日数に対する半減期90日の指数減衰で固定する。馬体重変化率は両方の馬体重がある場合だけ計算する。未取得を0kgの変化とは扱わない。保存履歴の直近は、実際のキャリアの直近を保証しない。現在の取得済み履歴にない走りを推測で補わない。

特徴量は対象レースの観測時点で結果が既知の履歴だけから作る。将来の結果を含む入力は拒否する。馬場別率・騎手勝率・調教師勝率を維持し、履歴件数の直接加点は行わない。オッズ混合は引き続き別成果物である。

```bash
python -m keiba_prediction_lab.cli evaluate-walk-forward \
  local/training.csv local/windows.json --recent-form-v4 \
  --report reports/recent-form-comparison.json
python -m keiba_prediction_lab.cli train-model \
  local/training.csv --recent-form-v4 --calibration-races 60 \
  --output local/recent-form-candidate.json
```

`--track-condition-v2`、`--evidence-neutral-v3` とは同時指定できない。モデル版は `conditional-logit-recent-form-v4`、校正ありは `-temperature-v1` を付ける。特徴量は23要素、成果物スキーマは1.4。従来1.0〜1.3の読込互換を維持し、スキーマ・モデル版・フラグ・ベクトル長の不整合は拒否する。

## 評価と運用

窓・入力・指標・近走の定義を結果計算前に固定し、現行v2およびv3と同じ期間で比較する。使い回した開発期間は未使用テストと呼ばない。1着一致が改善しても、確率誤差・校正が悪化した場合は昇格を保留する。候補の採否は新たな未使用開催でも確認する。直近開催の結果に合わせて半減期や履歴数を繰り返し調整しない。

この候補も単勝能力から着順を導く条件付きロジット／Plackett–Luceの枠内にある。専用の2・3着モデル、ワイド同時入着モデル、クラスを補正した時計・着差は含まない。近走着順は相手水準の補正済み能力ではない。

実データ・学習済みモデル・評価成績は端末ローカルに保存する。公開コードのテストは合成データのみで行う。
