# 時点整合的な特徴量

段階4では、対象レースの結果を見ずに再生成できる特徴量だけを扱う。実データは同梱せず、実装とテストは合成データで検証する。

## 時刻の契約

- `scheduled_at`: 発走予定時刻
- `observed_at`: 出馬情報を固定した時刻。必ず発走前とする
- `result_known_at`: 過去走の結果が利用可能になった時刻
- 過去走は `result_known_at <= observed_at` のものだけを入力できる。未来行を黙って除外せず、混入時は処理全体を失敗させる
- 馬体重は観測時刻に判明していなければ `None` とし、後から補完しない

## 特徴量一覧

| 特徴量群 | 基準時刻 | 参照期間 |
|---|---|---|
| 馬番、斤量、馬体重、距離帯 | `observed_at` | 対象レースのみ |
| 前走からの日数 | `observed_at` | 当該馬の直近1走 |
| 馬の勝率・3着内率 | `observed_at` | 入力された全過去走 |
| 同競馬場・芝ダート・馬場状態・距離帯の勝率 | `observed_at` | 当該馬の条件一致全過去走 |
| 騎手・調教師の勝率 | `observed_at` | 入力された全過去走 |

距離帯は `1400m以下`、`1401–1800m`、`1801–2400m`、`2401m以上` の4区分で固定する。勝率と3着内率は全体率を事前率にした加法平滑化を行い、集計数も同時に出力する。これにより、未出走馬と少数実績による極端な値を区別できる。

同着は、1着の信用を同着馬で等分する。3着内信用は各レースで最大3頭分になるよう等分する。入力順に依存しない集計順を使用し、同一入力から同一の出力を得る。

脚質と想定ペースは、予測時点で利用可能な定義と元データが確定していないため、この段階では追加していない。利用条件を確認した実データ源を承認した後に拡張する。
