# 三連単生成モデルの対応比較

勝率だけの`plackett-luce-v1`と、脚質・想定ペースを加えた`pace-scenario-v1`を、同一レース上で対応比較する。

## 比較条件

発走前に固定した二つのスナップショットについて、次が一致する場合だけ比較する。

- 対象レース
- 発走予定時刻と元予測時刻
- オッズ確認前・確認後の区分
- 入力データ版
- 1着勝率モデル版
- 1・3・5・10点のポートフォリオ契約

これにより、候補モデルだけ新しい入力を使用した比較や、異なる1着モデルを展開効果として誤認する比較を拒否する。

## 出力

各戦略・点数について、同じレースを次の4群へ分類する。

- 両モデルが的中
- 基準モデルだけ的中
- 候補モデルだけ的中
- 両モデルとも不的中

候補だけの的中数から基準だけの的中数を引いた値を純増として表示する。対応のある不一致レースには正確二項検定の両側p値を付ける。p値は効果の大きさではなく、観測差が偶然でも生じ得る度合いの診断値として扱う。

さらに、実際の三連単へ割り当てた確率から平均Log lossを計算する。上位点数へ入ったかだけでなく、全確率分布の質も比較できる。同着で複数の的中組み合わせがある場合は、その確率を合算する。

## 更新規則

比較結果は材料として保存するだけで、モデル・係数・購入点数を自動変更しない。固定した評価期間が終了した後に仮説を作り、別の未使用期間で再現した場合のみ、次のモデル版への採用候補とする。

影の3・5・10点は購入成績ではなく、追加候補の情報価値を調べる反実仮想である。実購入候補は引き続き1点100円に固定する。
