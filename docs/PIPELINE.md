# 1レース予測パイプライン

このパイプラインは、対象レースについて同じ入力と同じ予測時刻から、実購入候補と研究用の影予測を一度に生成して固定する。

## 固定する流れ

1. 学習済みの勝率モデルへ、発走前に確定した特徴量を入力する
2. 各馬の勝率・3着内率・予測順位を生成する
3. 標準の Plackett–Luce 三連単分布を生成する
4. 脚質・想定ペース条件付き三連単分布を別に生成する
5. 標準モデルの最上位三連単だけを実購入候補（1点100円）として固定する
6. 両モデルの1・3・5・10点を、購入額0円の影予測として固定する

出力先には `actual.json`、`baseline-shadow.json`、`pace-shadow.json`、`manifest.json` を保存する。既存の出力ディレクトリは上書きしない。

## 変更しないもの

- レース当日の入力による再学習や係数更新は行わない
- 予算やオッズに応じて勝率予測を変更しない
- 影予測を購入実績として集計しない
- 展開条件付きモデルを、検証なしに実購入候補へ昇格させない

現在のポリシー版は `research-one-ticket-v1` である。将来、同一レース群での事前固定比較により展開条件付きモデルの改善が確認されても、実購入モデルの変更は別の版として明示的に行う。

このAPIは、学習済みモデル、標準化済み特徴量、脚質プロファイル、想定ペースを受け取る外郭である。実データの取得、スクレイピング、学習は自動実行しない。対象レースと適法に利用できるデータ源が決まった後に、ローカルの入力アダプターを接続する。
