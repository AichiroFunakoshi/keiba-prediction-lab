# 1レース予測パイプライン

このパイプラインは、対象レースについて同じ入力と同じ予測時刻から、実購入候補と研究用の影予測を一度に生成して固定する。

## 固定する流れ

1. 学習済みの勝率モデルへ、発走前に確定した特徴量を入力する
2. 各馬の勝率・3着内率・予測順位を生成する
3. 標準の Plackett–Luce 三連単分布を生成する
4. 同じ標準分布から全6馬券種の完全確率表と最上位候補を生成する
5. 脚質・想定ペース条件付き三連単分布を別に生成する
6. 標準モデルの最上位三連単だけを実購入候補（1点100円）として固定する
7. 両モデルの三連単1・3・5・10点と全6馬券種の候補を、購入額0円の影予測として固定する

出力先には `actual.json`、`baseline-shadow.json`、`pace-shadow.json`、`bet-types-shadow.json`、`manifest.json` を保存する。既存の出力ディレクトリは上書きしない。現在のマニフェストスキーマ版は `1.1` である。

## 変更しないもの

- レース当日の入力による再学習や係数更新は行わない
- 予算やオッズに応じて勝率予測を変更しない
- 影予測を購入実績として集計しない
- 展開条件付きモデルを、検証なしに実購入候補へ昇格させない

現在のポリシー版は `research-one-ticket-v1` である。将来、同一レース群での事前固定比較により展開条件付きモデルの改善が確認されても、実購入モデルの変更は別の版として明示的に行う。

このAPIは、学習済みモデル、標準化済み特徴量、脚質プロファイル、想定ペースを受け取る外郭である。実データの取得、スクレイピングは自動実行しない。

## ローカル入力からの正式実行

保存済みモデル、過去結果、結果列のない対象馬、対象馬ごとの脚質プロファイル、レース全体の想定ペースを明示して実行する。

```bash
PYTHONPATH=src python -m keiba_prediction_lab.cli predict-race \
  local/model.json local/history.csv local/targets.csv \
  local/pace-profiles.csv local/pace-scenario.json \
  --frozen-at 2026-02-01T10:05:00+09:00 \
  --phase pre_odds --output outputs/race-1
```

`pace-profiles.csv`には、レース・馬ID、観測時刻、脚質（`leader`、`presser`、`stalker`、`closer`）、序盤速度、終盤速度、ペース耐性を含める。3つの数値は0から1とする。`pace-scenario.json`には、レースID、観測時刻、想定ペース（`slow`、`average`、`fast`）、確信度を含める。脚質・ペース・固定時刻は推測で補わず、対象CSVと同じ観測時刻で明示する。

モデル、履歴、対象、脚質、想定ペースの各ファイルは一度読み込んだ内容を検証・ハッシュ化に使用する。5つのSHA-256から結合入力版を生成し、`input-provenance.json`へ保存する。既存の出力ディレクトリは上書きも削除もしない。

複勝の払戻対象席数は `place_payout_slots` で明示できる。未指定時は予測対象が5～7頭なら2、8頭以上なら3とする。発売開始後に出走取消・競走除外があった場合は、発売開始時のルールに基づく値を入力側で渡す。
