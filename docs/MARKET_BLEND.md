# 市場混合予測

独立モデルを残したまま、発走前に時刻固定した単勝オッズを市場評価の一要素として加える別バージョンである。確定オッズ、着順、払戻は使わない。

## 方式

単勝オッズの逆数をレース内で正規化して市場確率を作る。モデル確率を `p_model`、市場確率を `p_market` とし、既定値では次を正規化する。

`p_blend ∝ p_model^0.65 × p_market^0.35`

市場を35%に留めるため、人気順をそのままコピーせず、独立モデルの馬・騎手・調教師・馬場・ペース等を主成分に残す。35%は過去結果で最適化した値ではなく、固定ウォークフォワード評価まで変更しない暫定値である。

## 時刻と保存

```bash
PYTHONPATH=src python -m keiba_prediction_lab.cli build-market-blend \
  local/race-day local/jra-refresh \
  --market-weight 0.35 \
  --output local/race-day/market-blend.json
```

- JRA取得マニフェストの取得時刻と `cards.json` のSHA-256を検証する
- 市場観測時刻以降に発走するレースだけを出力する
- 元の `actual.json` と影予測は変更・上書きしない
- 三連単の実候補は1点100円、3・5・10点は0円の影予測として分離する
- RaceWeaveは開催日マニフェストのSHA-256が一致する成果物だけを表示へ重ねる

本方式の昇格判断は、未使用期間を含まない固定ウォークフォワードで独立モデル、市場単独、複数の事前固定混合率を比較してから行う。
