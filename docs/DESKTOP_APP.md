# RaceWeave macOSアプリ

## 位置づけ

RaceWeaveは、既存の監査済み予測UIをmacOS専用ウインドウで表示するローカルアプリである。PWA、クラウドサービス、馬券購入アプリではない。Pythonの予測・監査ロジックをUIへ複製せず、従来と同じ`ReadOnlyAppSnapshot`とIPv4ループバックAPIを使う。

バージョン0.3はUI-1の読み取り専用機能を`.app`へ包装し、Finderから開くだけで同じリポジトリの`local/`にある最新の監査済み開催日成果物を表示する。学習、予測実行、結果取得、保存は行わず、既存CLIで生成された成果物の表示に限定する。

## アプリ名とアイコン

- 表示名：`RaceWeave`
- 読み：レースウィーヴ
- Bundle ID：`jp.aichiro.raceweave`
- 意味：1着確率を起点に、異なる2着・3着の展開を織り上げる
- アイコン原版：`assets/macos/RaceWeave.png`

アイコンは本プロジェクト用に生成した独自画像であり、JRAその他の団体ロゴ、公式画像、実データを含まない。三頭の馬と織り重なる軌道の形状を保ち、深いターフグリーン、栗毛、土色、アイボリーを基調とする。画面も同じ配色体系を使い、枠番色と正式候補の赤は識別情報として維持する。

## 初回ビルド

macOSとPython 3.11以上を使用する。同じリポジトリの`.venv`へデスクトップ版だけの依存を追加する。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[desktop]'
./build-raceweave-app.command
```

成功すると`dist/RaceWeave.app`が作られる。`dist/`、`build/`、PyInstallerの`.spec`はGit管理対象外であり、生成したアプリへローカルの実レースデータを同梱しない。

`build-raceweave-app.command`は、原版PNGをアプリアイコンへ変換し、WebKitウインドウ、Python実行環境、既存パッケージ、静的UIをひとつの`.app`へ包装する。iCloud等のFinderメタデータが署名へ混ざらないよう一時領域で組み立て、拡張属性を除去してad-hoc署名を検証してから`dist/`へ複製する。ビルド時にネットからデータを取得せず、必要なPythonパッケージが未導入なら停止する。

## 起動

Finderで`dist/RaceWeave.app`を開く。ブラウザとTerminalを操作する必要はない。アプリは同じチェックアウトの`local/`だけを読み取り専用で探索し、開催日と固定時刻が最も新しい、監査に成功した`race-day.json`を自動表示する。無効な候補は表示しない。

監査済み開催日が見つからない場合だけmacOS標準のファイル選択画面を開く。選択した開催日ディレクトリに監査可能な`walk-forward.json`または`win5.json`が隣接していれば、同じ画面へ関連付ける。別ディレクトリの同名ファイルを推測で混ぜない。

アプリは同じディレクトリの`race-day-provenance.json`を必須とし、開催日マニフェスト、モデル・履歴ハッシュ、固定時刻、予測段階、各入力来歴、全予測バンドルを再監査する。監査に失敗した場合は警告して表示しない。監査中の差し替えも検出するため、表示スナップショットの組み立て後に開催日全体をもう一度監査する。選択したパスは保存せず、元ファイルを編集・移動・複製しない。

旧形式の開催日成果物に馬番・馬名表示が含まれない場合は、同じ`local/`内に残る結果列のない対象CSVのうち、予測バンドルに記録された`targets_sha256`と完全一致するものだけをメモリ上で関連付ける。内容やハッシュが異なる入力、結果データ、別レースの入力は表示へ混ぜない。今後生成する開催日成果物には、同じ固定入力から得た馬番・馬名を`runner_display`として含める。

自動検出できず、ファイル選択もキャンセルした場合だけ、初回に次のGit管理外領域へ合成デモを作る。

```text
~/Library/Application Support/RaceWeave/ui-demo-v1
```

2回目以降は既存デモを変更せず、監査してから表示する。このデモは画面確認専用で、実レース予測や精度主張には使用できない。

開発中にファイル選択画面を使わず、監査済み実成果物を専用ウインドウで開く場合は、リポジトリの仮想環境から次のように起動する。

```bash
raceweave \
  --race-day-manifest outputs/2026-08-30/race-day.json \
  --walk-forward-report reports/walk-forward.json \
  --win5-forecast outputs/win5-2026-08-30.json
```

1レースだけなら`--prediction-bundle`を指定できる。開催日指定では完全な`race-day-provenance.json`を必須とする。`--demo-directory`と実成果物指定、`--race-day-manifest`と`--prediction-bundle`は同時に使えない。

## ローカル境界

- HTTP待受先は`127.0.0.1`だけで、空いている一時ポートを使用する
- 専用WebKitウインドウを閉じるとローカルHTTPサーバーも終了する
- テレメトリー、クラウドDB、外部アカウント、馬券購入機能を持たない
- 監査済みスナップショットだけを表示し、元成果物を変更しない
- 自動検出または選択したローカルパスを設定ファイルや履歴へ保存しない
- 実データ、モデル、予測、結果、レポートをGitHubへ追加しない
- APIキー、Apple署名証明書、プロビジョニング情報をリポジトリへ追加しない

## 配布範囲

当面は、所有者本人が同じMac上でビルドして使うad-hoc署名の個人利用版とする。Apple Developer IDによる配布用署名と公証はまだ行わない。GitHubではソース、合成テスト、アイコン原版、ビルド手順だけを公開する。他者へバイナリ配布する段階で、Developer ID署名、公証、依存ライセンス一覧、配布物に実データがないことを別途確認する。

### 表示用の単勝オッズ・人気

レース一覧、三連単の馬番、順位表、WIN5にはローカルに取得済みの最新のJRA単勝オッズと掲載人気を表示する。人気未掲載時は全頭のオッズが揃っている場合に限り単勝順を計算し「番人気相当」と明示する。同オッズは同順位。予測順位とは別であり、独自予測の順位・確率は変更しない。

取得時刻を表示する。表示は起動時の取得済みスナップショットによるもので、画面の再読込はJRAへの再取得ではなく自動更新も行わない。新たに取得したスナップショットはアプリの再起動で反映される。カードのハッシュと馬ID・馬番の対応が一致しない情報は表示へ結合しない。

### 一覧の画面内表示

デスクトップの表示領域が幅1051px以上・高さ740px以上の場合、一覧は画面の高さに合わせて12レースとWIN5を配置します。馬番・単勝オッズ・人気順・ワイド候補を表示し、予測条件や検証結果は「予測条件・検証結果」から展開します。市場比較へ切り替えると、上部の方式名も連動します。小さい画面や拡大表示では文字を切り捨てず、通常のスクロール表示に戻ります。レース詳細の長い根拠一覧は引き続きスクロールして確認できます。

ブラウザー検証時のローカル画像と操作記録は`output/playwright/`と`.playwright-cli/`に置き、Git管理から除外します。
