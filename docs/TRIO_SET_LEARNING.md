# 三連複専用学習の比較候補

`conditional-trio-set-v1` は、実際に3着以内に入った3頭の組合せを直接学習する条件付き集合モデル。勝率順位を三連複へ読み替える従来方式とは学習目的が異なる。各馬のスコアの和を指数化し、全3頭組で正規化する。学習勾配は、モデルの3着内包含確率と実際の3着内指標の差。動的計画法による包含確率は全組列挙と照合している。

能力v5と同じ発走前特徴量を使用し、騎手、馬・騎手の組合せ、近走、対戦相手、コース・馬場・距離適性などを引き継ぐ。時計・着差・クラス補正やペース相互作用を新たに実装したモデルではない。加法的スコアのモデルであり、馬同士の任意の相互作用までは学習しない。三連複専用なので、単勝・WIN5の確率として流用しない。

## 固定期間検証

```sh
python -m keiba_prediction_lab.trio_research evaluate \
  local/training.csv local/windows.json reports/trio-development
```

時間窓は既存の `train_end`, `calibration_end`, `evaluation_end` 形式。重複する評価窓は禁止。両方式に同一の特徴量・対象レースを用い、モデルの学習は最初の期間、温度校正は次の期間、評価は最後の期間で行う。モデルの次元、有限値、学習時刻、重複馬を検査する。

初版は5頭以上で、着順1〜頭数が欠けず重複しないレースのみ対応する。同着・中止等を含む対象外レースはIDと除外理由をレポートへ保存し、比較する両方式から同じように除く。固定期間の元レース数から減った数も明示する。欠けた着順を推定して埋めない。取得済み履歴による過去検証であり、全生涯履歴を保証しない。過去の観測・結果判明時刻に代理時刻を使った入力は、その前提を引き継ぐ。

的中数、順不同3頭のLog loss・Brier、選択3頭の一致数を記録する。払戻は学習目標にしない。既に参照した期間は開発検証として表示し、未使用開催での確認と区別する。

## 次回の同時計算

ローカル予測設定へ `trio_shadow_model`（設定ファイルからの相対パス）と `trio_shadow_sha256` を指定すると、`predict-profile-day` が従来予測に加えて `trio-model-shadow.json` を保存する。

- 新モデル単独、および新モデル80％＋市場20％を、同じレース入力・保存済み単勝オッズから同時計算。
- 市場側は単勝オッズを正規化した勝率から全三連複確率を作り、組合せ確率を対数プールで混合する。20％は対数確率に対する重み。
- 両候補は購入額0円の比較用。既存の主候補、WIN5、過去バンドルを変更しない。
- 設定読み込み時と生成前後にモデルハッシュを検査。入力の変化、馬ID不一致、欠損オッズ、発走済みレース、学習・校正以前の観測は拒否する。
- 元のモデル、履歴、出馬表、開催計画、市場スナップショットのハッシュと、生成・固定・市場取得時刻を保存する。

比較候補の採用判断は次の未使用開催の事前固定予測から行う。直近の事後検証でよかった20％を最適比率と断定しない。市場比率比較は同じ新モデルで0・20・50・80・100％を一度に比べ、結果を見て候補を追加し続けない。

## アプリ

ローカルの `trio-research.json` に固定期間検証ファイルへの相対パスとSHA-256を設定すると、アプリの「予測条件・検証結果」に開発検証を表示する。集計はレース明細から再計算して照合する。現在の保存済み予測と混同しないよう、未使用開催での確認待ちと明記する。レポートやモデルはGit管理しない。

単独の学習・発走前参考予測も実行できる。

```sh
python -m keiba_prediction_lab.trio_research train local/eligible-training.csv local/trio-model.json
python -m keiba_prediction_lab.trio_research predict \
  local/trio-model.json local/history.csv local/targets.csv outputs/trio-shadow.json \
  --frozen-at 2099-01-01T10:00:00+09:00
```

時刻は実際の開催に合わせ、現在時刻より後かつ発走前に設定する。初版の単独trainは未校正モデルを作る。校正を行う場合は学習より後のレースだけを用い、選んだ温度と校正期間をモデルへ保存する。未来のモデルを過去開催へ適用して当時の予測として報告しない。

## 指定日の新モデル主表示

利用者が指定した日の新モデル予想を主表示にする場合、`save_direct_trio_display` を全レース発走前に実行する。既存の予測バンドルを置換せず、`direct-trio-display.json` で開催日と事前保存済み `trio-model-shadow.json` のハッシュを固定する。アプリは同一履歴・計画・対象入力、発走時刻、全組合せ分布、最上位候補を検査し、新モデル単独の三連複を表示する。比較ボタンは同じモデルと入力の市場20％版へ切り替える。

一覧は三連複分布から計算した3着内包含確率の最上位馬と、その3着内率を表示する。勝率は三連複確率から作らず、詳細画面の勝率順位表・要因は従来モデルの参考値として明示する。新モデルの全体採用や過去の購入記録変更とは別の表示指定であり、次開催の優位性を保証しない。天気から推定した馬場は公式発表と区別し、入力・根拠をローカル保存する。騎手の率は取得履歴の集計であり、全騎乗履歴・直近限定の専用係数を保証しない。
