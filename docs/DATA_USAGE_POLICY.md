# 外部データ利用方針

この方針は、公開するプログラムコードと、利用者がローカルで用意する外部競馬データを明確に分離するためのものです。

## 基本構成

```text
GitHubで公開するもの
  ├─ データ形式、検証、特徴量生成、学習、評価のコード
  ├─ データ取得元を差し替えられるインターフェース
  ├─ ライセンスと出所の監査台帳
  └─ 実在の競走を含まない合成テストデータ

利用者のローカル環境だけに置くもの
  ├─ 利用者が正当な方法で取得したレースデータ
  ├─ 有料サービスの契約データ
  ├─ 認証キー、Cookie、アカウント情報
  └─ 原データから生成した非公開の中間ファイル
```

## 利用者の責任

本プロジェクトのライセンスは、外部データを取得、複製、加工、学習利用、再配布または公開する権利を利用者へ付与しません。

利用者は、外部データを使用する前に、自ら次を確認する必要があります。

- 提供元の利用規約とライセンス
- 自動取得、保存、加工、機械学習への利用が許されるか
- 個人利用、研究利用、公開、商用利用の区別
- 原データや派生データを第三者へ再配布できるか
- 公式API、SDK、専用ソフトなど指定された取得方法があるか

判断できない場合は取得・利用・公開を止め、提供元または専門家へ確認してください。

## 禁止する設計

このリポジトリでは、次を標準機能として提供しません。

- 提供元が禁止する自動アクセスを行う取得器
- アクセス制御、認証、レート制限などを回避する機能
- 外部サービスの秘密情報をコードへ埋め込む機能
- 利用条件が確認できない原データやデータベースの同梱
- 外部データをGitHubや配布物へ自動的にアップロードする機能

## JRA・JRA-VANを利用する場合

JRA公式ホームページの掲載物と、JRA-VANの契約データは同じものとして扱わない。それぞれの最新条件を確認する。

JRA-VAN Data Lab.を利用する実装を将来追加する場合は、原則として次の構成にする。

1. 利用者本人がJRA-VANと契約する
2. 利用者のWindows環境で公式JV-Linkを使用する
3. 利用者のローカル保存領域へデータを出力する
4. 本プログラムはローカルファイルを読み込んで分析する
5. 契約データ、利用キー、原データをGitHubへ送信しない

JRA-VANの一般利用規約は、本人による私的使用以外の利用や公表を制限している。公開サービス、第三者へのデータ提供、データ同梱を行う場合は、通常の個人利用とは別の許諾・手続が必要になり得る。

## 免責の限界

「自己責任」と記載することだけで、提供元の規約、著作権、契約上の制限、アクセス制限に反する行為が許されるわけではありません。本方針は法的助言ではなく、安全側に運用するためのプロジェクト規則です。
