# 全6馬券種の事前シャドー予測

単勝、複勝、馬連、馬単、3連複、3連単について、発走前の同一入力から完全な確率表と最上位候補1点を生成する。これらは購入しない研究用シャドー予測であり、実購入候補の三連単1点100円とは別ファイルへ固定する。

## 確率の作り方

基準モデルは各馬の勝率を重みとする Plackett–Luce 分布から、順序付き上位3頭の全組合せを生成する。その同じ同時分布を次のように周辺化する。

| 馬券種 | 確率 |
|---|---|
| 単勝 | 同時分布を1着馬について合計した確率 |
| 複勝 | 同時分布を払戻対象の2着内または3着内について合計した確率 |
| 馬単 | 3着馬について合計した、1着・2着順序付き確率 |
| 馬連 | 1着・2着の順序をまとめた確率 |
| 3連単 | 順序付き上位3頭の同時確率 |
| 3連複 | 上位3頭の順序をまとめた確率 |

単勝、馬連、馬単、3連複、3連単の各確率表は合計1になる。複勝の合計は払戻対象の席数と同じ2または3になる。

[JRAの複勝式](https://www.jra.go.jp/kouza/yougo/w432.html) は発売開始時の出走頭数が5～7頭なら2着まで、8頭以上なら3着までを的中とし、4頭以下では発売しない。このため全6馬券種の予測は5頭以上を必須とし、`place_payout_slots` に2または3を記録する。未指定時は予測対象の頭数から推定するが、発売開始後の取消・除外で頭数が変わった場合は、発売開始時の条件に合わせて明示的に指定する。

馬連と3連複の馬IDは辞書順に正規化し、同じ組合せの重複を防ぐ。各馬券種は確率の降順、同率なら馬IDの辞書順で並べ、先頭を最上位候補とする。入力行の並びを変えても結果は変わらない。

## 固定する内容

`bet-types-shadow.json` には次を保存する。

- レースID、発走予定時刻、固定時刻、元予測時刻
- オッズ確認前後の区分
- 入力データ版、モデル版、生成器版
- 複勝の払戻対象席数（2または3）
- 全6馬券種の完全な確率表
- 全6馬券種の最上位候補1点ずつ
- 正規化した内容の SHA-256

既存ファイルは上書きせず、内容改変は読込時の整合性検査で拒否する。購入額の項目は持たず、パイプラインのマニフェストでも `stake_yen: 0` として実購入記録から分離する。

現在のスキーマ版は `1.0`、生成器版は `plackett-luce-marginals-v1` である。払戻やオッズは候補選択に使用しない。結果確定後の比較は、馬券種を混ぜず [BET_TYPE_EVALUATION.md](BET_TYPE_EVALUATION.md) の固定100円ルールで行う。
