# プロジェクト原則

## 目的

このプロジェクトは競馬の着順予測を研究し、予測確率の精度と再現性を高めることを目的とする。利益最大化、自動投票、購入額最適化は目的に含めない。

## 予測対象

初期段階では次を予測する。

1. 各馬の勝率
2. 各馬の3着内率
3. レース内の予想着順

単勝・複勝・3連複・3連単などの買い目は、予測結果から独立した規則で生成する。

## 購入額

すべての買い目は1点100円とする。資金量、確信度、期待値によって購入額を変更しない。複数点を購入した場合は、点数×100円をそのレースの購入額として記録する。

## 評価指標

### 予測精度

- 1着的中率
- 3着以内判定の精度
- 上位3頭の順不同的中率
- 3連単完全一致率
- Brier score
- Log loss
- 確率校正

### 固定額シミュレーション

- 的中率
- 総購入点数
- 1レース平均購入点数
- 総購入額
- 総払戻額
- 回収率
- 最高払戻を除外した回収率
- 上位1件、3件、5件の払戻集中度

回収率は学習目的として直接最大化せず、着順確率から生じた結果として測定する。

## 情報漏洩の防止

対象レースの確定着順、走破タイム、上がり、通過順位、払戻、確定後にのみ得られる情報を予測入力に使用しない。オッズを使用する実験では、取得時刻を保存し、独立予想とは別モデルとして扱う。

## 検証方法

ランダム分割を基本検証に使用しない。過去で学習し、その後の期間で検証するウォークフォワード方式を採用する。モデル選択に使った期間と最終評価期間を分離する。

## データ利用

無料であることと、自由に再配布できることは同義ではない。各データについて、取得元、取得方法、ライセンス、利用規約、取得日時、予測時点で利用可能だったかを記録する。確認できない実データはGit管理しない。
